# Release Roadmap (Production)

## Phase A: Core foundation (current)

- API scaffold and contract
- Local DB schema with migration-ready structure
- Community/check-in/chat baseline endpoints

## Phase B: Production hardening

- Postgres migration + migration tooling
- JWT auth + refresh token + device session management
- Object storage for media (S3-compatible)
- Rate limit and anti-abuse controls

## Phase C: Quality and compliance

- Crash analytics and performance metrics
- Community moderation dashboard
- Privacy policy + ToS + crisis response handbook
- App Store / Google Play content review preparation

## Phase D: Launch

- Closed beta (TestFlight + Internal Testing)
- Security audit checklist
- Public release
